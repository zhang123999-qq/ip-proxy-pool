## 四、架构变更

### 旧（单层 HTTP）

```
[item] → [HTTP probe 10s] → +1 / -3
```

### 新（2 层 + 投票 + 重试 + 复用 client）

```
[item]
  ↓ L1 TCP 预筛（asyncio.open_connection，1s 超时，1000 并发，不限令牌桶）
  ↓ 失败 → 直接 -3，不进 L2
[item]
  ↓ L2 HTTP 投票（500 并发，复用 AsyncClient）
  ↓ 3 URL 并发探测（每 URL 2s 超时）
  ↓ 走令牌桶（全局 300 req/s）
  ↓ 收集成功数 >= 2/3 → +1
  ↓ 否则 → 重试 1 次（仅 VALIDATE_RETRY_ONCE=True）
  ↓ 重试仍失败 → -3
```

### 关键代码片段

#### ① TCP 预筛层（极便宜）

```python
async def _tcp_probe(self, item: ProxyItem) -> bool:
    """1 秒 TCP 握手，70% 死代理在这一步被剔除"""
    try:
        reader, writer = await asyncio.wait_for(
            asyncio.open_connection(item.ip, item.port),
            timeout=VALIDATE_TCP_TIMEOUT,
        )
        writer.close()
        try:
            await writer.wait_closed()
        except Exception:
            pass
        return True
    except (asyncio.TimeoutError, ConnectionRefusedError, OSError):
        return False
```

**单次耗时 < 200ms**，1000 并发下本地 socket 池够用。

#### ② 令牌桶限 L2 速率

```python
class _AsyncTokenBucket:
    """异步令牌桶，全局限目标 URL 速率"""
    def __init__(self, rate: float, capacity: Optional[float] = None):
        self.rate = float(rate)
        self.capacity = float(capacity if capacity is not None else rate)
        self._tokens = self.capacity
        self._last = time.monotonic()
        self._lock = asyncio.Lock()

    async def acquire(self) -> None:
        async with self._lock:
            now = time.monotonic()
            elapsed = now - self._last
            self._tokens = min(self.capacity, self._tokens + elapsed * self.rate)
            self._last = now
            if self._tokens < 1:
                wait = (1 - self._tokens) / self.rate
                self._tokens = 0
                await asyncio.sleep(wait)
            else:
                self._tokens -= 1
```

L1 TCP 层**不**走令牌桶（CDN 不在乎 TCP 失败）；L2 HTTP 层走。

#### ③ HTTP 投票层（核心）

```python
async def _http_probe_one(self, item, url, client, results, proxy_url):
    """探测单个 URL"""
    try:
        await self._rate_limiter.acquire()
        resp = await client.get(url, proxy=proxy_url, timeout=VALIDATE_TIMEOUT)
        if resp.status_code == 200:
            body = resp.text
            # 关键：剔透明代理 — body 必须含代理 IP
            if item.ip in body:
                results[url] = True
                return
            else:
                self._stats["transparent_killed"] += 1
                results[url] = False
                return
        results[url] = False
    except Exception:
        results[url] = False
```

**透明代理剔除**是核心：透明代理能访问任何 URL，但 body 不一定含代理 IP。

#### ⑤ 重试容错

```python
async def _validate_one(self, item, client):
    # L1 TCP
    if not await self._tcp_probe(item):
        return item, False

    # L2 HTTP 投票
    results = await self._http_probe(item, client, proxy_url)
    passes = sum(1 for ok in results.values() if ok)
    if passes >= VALIDATE_PASS_THRESHOLD:
        return item, True

    # 失败重试 1 次
    if VALIDATE_RETRY_ONCE:
        results = await self._http_probe(item, client, proxy_url)
        passes = sum(1 for ok in results.values() if ok)
        if passes >= VALIDATE_PASS_THRESHOLD:
            return item, True

    return item, False
```

## 九、暂缓项（v3.1 候选）

- **VALIDATE_KEEP_LAST_OK**（高分代理跳过本轮验证）：预期省 15% 时间，但变量多易排错
- **多阶段验证**（TCP → TLS → HTTP → target）：复杂度提升 5×，收益边际
- **持久化 last_validated_at**：需要 schema 升级 + 迁移

老板拍板 v3.1 上不上前，先观察一周 v3 表现。

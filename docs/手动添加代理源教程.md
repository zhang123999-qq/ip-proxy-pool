# 手动添加代理源 教程

> 零代码动态扩展代理池，不用改代码、不用重启服务。
> 适合"找到一个新代理平台，要立刻接入"的场景。

---

## 0. 30 秒概览

代理池内置 15 个免费源，但免费源经常改版/失效。
与其"改代码 → 提交 → 重启"，现在能直接通过 HTTP API 增/删/启停：

```bash
# 加一个 GitHub raw 源（最快上手）
curl -X POST http://127.0.0.1:8000/admin/sources \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <ADMIN_TOKEN>" \
  -d '{
    "name": "my-github",
    "type": "text",
    "url":  "https://raw.githubusercontent.com/roosterkid/openproxylist/main/HTTPS_RAW.txt",
    "proto":"https"
  }'

# 看列表
curl -H "Authorization: Bearer <ADMIN_TOKEN>" http://127.0.0.1:8000/admin/sources

# 删除
curl -X DELETE -H "Authorization: Bearer <ADMIN_TOKEN>" \
  http://127.0.0.1:8000/admin/sources/my-github
```

保存到 SQLite，重启服务依旧生效。
下轮爬取就自动跑这个源，和内置源享受同一套**限速 / 重试 / 反爬 / 熔断**能力。

## 1. 三种源类型

| type  | 适用场景 | 解析方式 | 典型源示例 |
|-------|---------|---------|-----------|
| `text`  | 纯文本，每行一条 `ip:port` | 正则提取 `ip:port` | GitHub raw .txt、proxyscrape API |
| `table` | HTML 表格 `<table><tr><td>...</td></tr></table>` | BeautifulSoup 解析 | 89ip、快代理、free-proxy-list.net |
| `api`   | 通用文本/JSON 接口 | 文本按 `text` 解析 / JSON 按数组解析 | proxyscrape、openproxylist、proxy-list.download |

**如何选？** 浏览器打开目标 URL，搜索 `IP` 或 `port` 或冒号：

- 看到的是 `<td>` 表格 → `table`
- 是 `ip:port` 一行一个 → `text`
- 是 `{"ip":"...", "port":...}` → `api`（设 `json: true`）

## 2. 完整请求结构

### 2.1 POST /admin/sources

```jsonc
{
  "name":   "my-source",          // 必填，唯一名（字母/数字/中划线/下划线）
  "type":   "text",               // 必填，text / table / api
  "url":    "https://...",        // 必填，目标 URL（http/https）
  "proto":  "http",               // 可选默认协议，http / https，默认 http
  "config": { /* 每种 type 字段不同，见下文 */ },
  "enabled": true                 // 可选，默认 true
}
```

**返回**（200）：
```json
{
  "code": 0,
  "msg":  "已添加源 [my-source]",
  "data": {
    "id": 1,
    "name": "my-source",
    "type": "text",
    "url":  "https://...",
    "proto":"http",
    "config": {},
    "enabled": true,
    "created_at": 1788669359.79,
    "updated_at": 1788669359.79,
    "preview_name": "my-source",
    "active_sources_total": 16
  }
}
```

### 2.2 其他端点

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/admin/sources` | 新增自定义源 |
| GET  | `/admin/sources` | 查全部自定义源（含 disabled） |
| DELETE | `/admin/sources/{name}` | 删除源（内置源不可删，删除失败 404） |
| POST | `/admin/sources/{name}/toggle` | `{"enabled": false}` 停用 / 启用（保留在 DB） |

> ⚠️ 所有 `/admin/*` 路由都需要 `ADMIN_TOKEN`（`Authorization: Bearer <token>`）。
> 未设置时鉴权关闭（开发模式），生产环境务必设置。详见 [README.md](../README.md) 「环境变量」一节。

## 3. 各 type 详细字段

### 3.1 type = `text`

适用：纯文本每行 `ip:port`，最常见也最稳定。

```json
{
  "name": "my-text",
  "type": "text",
  "url":  "https://example.com/proxies.txt",
  "proto": "http",
  "config": {
    "headers": {                       // 可选：自定义请求头
      "User-Agent": "my-crawler/1.0"
    },
    "encoding": "utf-8"                // 可选：默认 utf-8
  }
}
```

**识别格式**：`1.2.3.4:8080` / `1.2.3.4 8080` / `1.2.3.4,8080`

**实测可用源（2026-09 验证）**：
- `https://raw.githubusercontent.com/TheSpeedX/PROXY-List/master/http.txt`（每天更新，~30k 条 http）
- `https://raw.githubusercontent.com/roosterkid/openproxylist/main/HTTPS_RAW.txt`（每天更新，~5k 条 https）
- `https://api.proxyscrape.com/v2/?request=displayproxies&protocol=http&timeout=5000&country=all`
- `https://api.openproxylist.xyz/http.txt`

### 3.2 type = `table`

适用：HTML 表格，自动定位 `ip` / `port` 列。

**打开浏览器 DevTools → 检查 → 找到 `<tr><td>`**

示例 HTML：
```html
<table>
  <tr><td>1.2.3.4</td><td>8080</td><td>HIGH</td><td>http</td></tr>
  <tr><td>5.6.7.8</td><td>3128</td><td>HIGH</td><td>https</td></tr>
</table>
```

→ 第 0 列 = IP，第 1 列 = 端口，第 3 列 = 协议。所以：

```json
{
  "name": "my-table",
  "type": "table",
  "url":  "https://example.com/list",
  "proto": "http",
  "config": {
    "ip_col":    0,                              // 必填：IP 列下标
    "port_col":  1,                              // 必填：端口列下标
    "proto_col": 3,                              // 可选：协议列下标（-1 = 用 proto 默认）
    "https_col": -1,                             // 可选：https 支持列（yes/no），如 free-proxy-list.net
    "pagination": {                              // 可选：翻页
      "param": "page",
      "start": 1,
      "end":   3
    },
    "headers": {                                 // 可选：自定义请求头
      "Referer": "https://example.com/"
    }
  }
}
```

**翻页规则**：
- 不填 pagination → 只爬首页
- `pagination.param` → URL 查询参数名（`?page=N`）
- start-end → 闭区间 `[start, end]`

**免费表格源（2026-09 验证）**：
- `https://www.89ip.cn/index_1.html`（列：ip=0, port=1，无协议列 → proto=http）
- `https://free-proxy-list.net/`（列：ip=0, port=1, https=6 yes/no）

### 3.3 type = `api`

适用：返回 JSON 或纯文本的 API。

```json
{
  "name": "my-api",
  "type": "api",
  "url":  "https://example.com/api/proxies",    // 不填 sub_urls 时用这个
  "proto": "http",
  "config": {
    "sub_urls": [                                // 可选：多 URL 不同 proto
      { "url": "https://example.com/api/http",  "proto": "http"  },
      { "url": "https://example.com/api/https", "proto": "https" }
    ],
    "json":    true,                             // 可选：返回 JSON 而不是纯文本
    "headers": {                                 // 可选：自定义请求头（含 Authorization）
      "Authorization": "Bearer xxx"
    }
  }
}
```

**JSON 识别格式**（按顺序找字段名）：
- IP 字段：`ip` / `IP` / `address`
- 端口字段：`port` / `Port` / `p`

## 4. 真实示例（复制即用）

### 4.1 GitHub 仓库聚合（最高产，最稳）

```bash
curl -X POST http://127.0.0.1:8000/admin/sources \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $ADMIN_TOKEN" \
  -d '{
    "name":"gh-speedx-http",
    "type":"text",
    "url":"https://raw.githubusercontent.com/TheSpeedX/PROXY-List/master/http.txt",
    "proto":"http"
  }'
```

### 4.2 HTML 表格 + 多页

```bash
curl -X POST http://127.0.0.1:8000/admin/sources \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $ADMIN_TOKEN" \
  -d '{
    "name":"my-89ip",
    "type":"table",
    "url":"https://www.89ip.cn/index_1.html",
    "proto":"http",
    "config":{
      "ip_col":0, "port_col":1,
      "pagination":{"param":"index","start":1,"end":3}
    }
  }'
```

注意 89ip 翻页是 `index_2.html` 这种格式 → 它**不是**查询参数翻页，用 `text` 手写多 URL 更合适：

```bash
curl -X POST http://127.0.0.1:8000/admin/sources \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $ADMIN_TOKEN" \
  -d '{
    "name":"my-89ip-text",
    "type":"text",
    "url":"https://www.89ip.cn/",
    "proto":"http"
  }'
```

表格会**自动** fallback 到文本提取（`parse_table_or_text` 同时支持）→ 这条照样能工作。

### 4.3 API + 鉴权头

```bash
curl -X POST http://127.0.0.1:8000/admin/sources \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $ADMIN_TOKEN" \
  -d '{
    "name":"my-api-json",
    "type":"api",
    "url":"https://example.com/api?type=http",
    "proto":"http",
    "config":{ "json": true, "headers": { "X-Api-Key":"xxx" } }
  }'
```

## 5. 调试：我加的源怎么验证？

### 5.1 立刻手动跑一次

```bash
curl -X POST "http://127.0.0.1:8000/proxy/refresh?mode=direct"
```

返回 JSON 里能看到：
- `fetched`: 采到多少条
- `added`: 入池多少
- `proxy_used`: 用了哪些代理

### 5.2 看日志

```bash
# Windows
tail -f D:\ip-proxy-pool\logs\app.log | findstr "my-source"

# *nix
tail -f logs/app.log | grep my-source
```

会看到：
- `[my-source] 启动爬虫 (mode=direct, proxies=...)` → 启动了
- `[my-source] HTTP 403` → 被风控（用代理爬源试试，或换 headers）
- `[my-source] 采集到 0 条` → 解析配置错了（重新对列下标）
- `[my-source] 采集到 35 条` → ✅ 生效

### 5.3 看被分配的代理

```bash
curl http://127.0.0.1:8000/proxy/crawl-mode
```

### 5.4 单源测：直接 Python 调用工厂

```python
import asyncio
import sys
sys.path.insert(0, "D:/ip-proxy-pool")
from storage.dao import custom_source_dao
from crawler.custom import build_crawler_from_source

src = custom_source_dao.get("my-source")
crawler = build_crawler_from_source(src)
items = asyncio.run(crawler.fetch())
print(f"采到 {len(items)} 条")
for it in items[:5]:
    print(f"  {it.key} ({it.protocol.value})")
```

## 6. 高级：从代码层自定义（API 满足不了时）

完全自动化的解析有边界——有些源需要登录、JS 计算、加密字段。
**这时还是要写代码**，但写起来非常简单：

### 6.1 文件 `crawler/custom.py` 里直接加

```python
import asyncio
from typing import List
from .base import BaseCrawler
from models import ProxyItem

class MySpecialCrawler(BaseCrawler):
    """我自定义的源，需要先登录再解析"""
    name = "my-special"

    async def fetch(self) -> List[ProxyItem]:
        # 1. 登录拿 cookie
        login_html = await self._get_html("https://example.com/login")
        # ... 解析 token / 算签名

        # 2. 带 cookie 请求
        api_data = await self._get_json(
            "https://example.com/api/proxies",
            headers={"Authorization": "Bearer xxx"},
        )

        # 3. 转 ProxyItem
        items = []
        for row in api_data["list"]:
            items.append(
                self.make_item(row["ip"], row["port"], "https")
            )
        return items
```

### 6.2 在 `crawler/sources.py` 末尾注册

```python
BUILTIN_CRAWLERS.append(MySpecialCrawler())
```

重启服务即生效——和动态添加的源走同一套调度。

### 6.3 进阶：直接在 `BUILTIN_CRAWLERS` 里**再追加**

写在代码里、内置调度、自己改自己部署。这样源码里有版本控制，不依赖数据库。

## 7. 高级：直接编辑 SQLite

API 背后是 `data/proxy_pool.db` 的 `custom_sources` 表。
**你也可以直接 SQL 操作**——比如批量导入：

```sql
-- 一次性导入 10 个 GitHub raw 源
INSERT INTO custom_sources (name, type, url, proto, config_json, enabled, created_at, updated_at)
VALUES
  ('gh-1', 'text', 'https://raw.githubusercontent.com/.../http.txt',
   'http', '{}', 1, strftime('%s','now'), strftime('%s','now')),
  ('gh-2', 'text', 'https://raw.githubusercontent.com/.../https.txt',
   'https', '{}', 1, strftime('%s','now'), strftime('%s','now')),
  -- ... 更多
;
```

```bash
sqlite3 data/proxy_pool.db < my-sources.sql
```

> 重启服务才会生效（manager 单例是懒加载）。

## 8. 常见问题

### Q1：加完没生效？
检查 `enabled` 字段是否为 `true`，或调用：
```bash
curl http://127.0.0.1:8000/admin/sources  # 看列表
```

### Q2：list 接口里看不到，但代码里好像生效了？
`GET /admin/sources` 只列**自定义**源。内置 15 个源另外在 `crawler/sources.py` 里。

### Q3：加了源后采集到 0 条？
- 404 / 403 → URL 错了或要登录/反爬
- 200 但 0 → 列下标错了（看 DOM）
- SSL 错 → 看日志，可能是证书过期

### Q4：会不会影响性能？
限速是全局令牌桶，单源再多代理源也只 2 req/s。放心加。

### Q5：能加多少个？
理论上不限。DDL 建议保持单 source < 100，太多反而拉低下游源的可信度。

### Q6：怎么备份 / 迁移？
```bash
cp data/proxy_pool.db data/proxy_pool.db.bak
```
整个 DB 文件就是"配置 + 代理"的完整快照。

## 9. 总结

| 想做什么 | 怎么做 |
|---------|-------|
| 加一个 GitHub 仓库源 | `POST /admin/sources`，type=`text` |
| 加一个 HTML 表格源 | `POST /admin/sources`，type=`table`+列下标 |
| 加一个 JSON API 源 | `POST /admin/sources`，type=`api`+`json:true` |
| 临时禁用某个源 | `POST /admin/sources/{name}/toggle` `{"enabled":false}` |
| 永久删掉 | `DELETE /admin/sources/{name}` |
| 看所有动态源 | `GET /admin/sources` |
| 复杂源（登录/JS/加密） | 写代码 `crawler/custom.py` → 加进 `BUILTIN_CRAWLERS` |
| 批量导入 | 直接 SQL 写 `custom_sources` 表 |
